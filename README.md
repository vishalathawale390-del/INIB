# INIB Internship Tasks

This repository contains the tasks I completed during my internship with **Intern InfoByte** in the Data Analytics / Python domain.

The projects are based on practical datasets and focus on data analysis, visualization, data cleaning, and machine learning.

## Tasks Completed

### Task 1 — Supplement Sales Data Analysis

This project focuses on analyzing supplement sales data to understand sales performance and identify useful patterns.

**Tools used:**

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

**Work completed:**

* Loaded and explored the dataset
* Checked data types and missing values
* Checked for duplicate records
* Cleaned the dataset
* Analyzed monthly sales trends
* Compared sales across categories
* Identified the top 10 products by revenue
* Analyzed region-wise sales
* Created a correlation heatmap

**Folder:** `Task-1-Supplement-Sales-Analysis`

---

### Task 2 — Customer Segmentation using K-Means Clustering

This project uses K-Means clustering to divide data into different groups based on quantity purchased and order amount.

**Tools used:**

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Jupyter Notebook

**Work completed:**

* Loaded and explored the dataset
* Checked missing values
* Cleaned the data
* Selected relevant features
* Standardized the data using `StandardScaler`
* Used the Elbow Method to determine the number of clusters
* Applied K-Means clustering
* Added cluster labels to the dataset
* Visualized the different clusters
* Counted records in each cluster
* Compared the average quantity and amount for each cluster
* Exported the clustered data to a CSV file

**Folder:** `Task-2-Customer-Segmentation`
